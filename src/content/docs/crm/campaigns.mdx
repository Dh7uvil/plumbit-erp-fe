Campaigns group marketing or sales outreach efforts. Link leads and opportunities to a campaign for attribution reporting.

<AppLink href="/campaigns">Open campaigns</AppLink>

## Purpose

| Use | Detail |
|---|---|
| **Attribution** | Track which campaign sourced a lead or opportunity |
| **Planning** | Name, date range, budget, status |
| **Reporting** | Campaign performance via CRM reports |

## Typical fields

| Field | Purpose |
|---|---|
| **Name** | Campaign identifier |
| **Status** | Active, completed, or cancelled |
| **Start / end date** | Campaign window |
| **Budget** | Optional planned spend |
| **Description** | Internal notes |

Leads and opportunities carry an optional **campaign** reference. Filter and report by campaign to measure conversion.

## Lifecycle

Create campaign → set active → assign to new leads/opportunities during the window → mark completed when done. Historical links remain on converted records.
