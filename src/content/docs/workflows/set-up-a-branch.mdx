Add an operating branch for document headers, filters, and reporting. Branches do **not** restrict stock or user visibility.

<Steps>
<Step title="Open branches">
<AppLink href="/organization-settings">Organization settings</AppLink> → **Branches** tab. Or see <DocLink href="/docs/organization-and-access/branches">Branches</DocLink>.
</Step>

<Step title="Create branch">
Enter code, name, status (`ACTIVE`), optional default currency, timezone, and address.
</Step>

<Step title="Use on documents">
Select branch on sales, purchase, inventory, and accounting document headers. Branch appears in list filters and reports — independent of warehouse.
</Step>
</Steps>

Branches are **not** linked to warehouses — see <DocLink href="/docs/organization-and-access/warehouses-setup">Warehouses setup</DocLink>.
