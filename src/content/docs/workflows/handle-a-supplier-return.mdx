Send received stock back to a supplier: post a purchase return to issue stock and clear GRNI, then post a debit note to reduce AP.

<Prerequisites>
- A **posted** goods receipt
- Return qty within returnable limit per GRN line (accepted + on hold minus prior returns)
- Permissions for purchase returns and debit notes
</Prerequisites>

<Steps>
<Step title="Create purchase return from GRN">
<AppLink href="/purchase-returns">Open purchase returns</AppLink> — create from posted GRN. Select lines, qty, and reason (DAMAGED, QUALITY_REJECTION, WRONG_ITEM, OVER_SHIPMENT, OTHER).

If goods were QC-rejected with **RETURN_TO_SUPPLIER**, they remain on QC hold until this return posts — see <DocLink href="/docs/inventory/quality-inspections-and-qc-hold">Quality inspections</DocLink>.
</Step>

<Step title="Post purchase return">
**Post** — issues stock from original GRN FIFO layers; GRNI reduced.

  rows={[

</Step>

<Step title="Create and post debit note">
Create <DocLink href="/docs/purchases/debit-notes">debit note</DocLink> from the posted return (or linked PI). **Post** — AP reduced; no stock movement.

  rows={[
    { action: "Post debit note", stock: "No change", reserved: "No change", gl: "Dr AP; Cr GRNI or expense", tax: "VAT reversed", documents: "PI qty_debited updated if linked" },

</Step>

<Step title="Refund or net (optional)">
Record supplier refund via <DocLink href="/docs/purchases/supplier-payments">supplier payment</DocLink>, or net debit against open bills.
</Step>
</Steps>

## QC reject path

GRN post → QC inspection reject (RETURN_TO_SUPPLIER) → purchase return post → debit note post. Full P2P exception branch in <DocLink href="/docs/workflows/procure-to-pay">Procure to pay</DocLink>.

## Cancel guards

- Posted purchase return cannot cancel if period locked or live debit note references it
- Posted GRN cannot cancel while a live purchase return exists
