## Line disposition

Each line requires a **disposition** controlling stock and GL:

| Disposition | Stock effect | GL on post |
|---|---|---|
| **RESTOCK** | On hand + (`RETURN_IN` at original cost) | Dr Inventory, Cr COGS |
| **QC_HOLD** | On hand + with QC hold flag | Dr Inventory, Cr COGS; available reduced until QC release |
| **SCRAP** | On hand + then `DAMAGE` movement out | Dr Stock scrap, Cr Inventory (restock GL reversed by scrap) |

<Callout type="note">
QC hold increases on hand but reduces **available** until released — same rules as goods receipt QC — see <DocLink href="/docs/inventory/stock-concepts">Stock concepts</DocLink>.
</Callout>

## Create from

| Source | Requirement |
|---|---|
| Delivery note | Must be **POSTED**; return qty ≤ delivered qty on each line |

Follow with a **credit note** from the return or source invoice for the commercial credit.

<Example title="Restock return">
DN-0042 delivered 20 widgets. Return 3 as RESTOCK → on hand +3 at original FIFO cost; Dr Inventory, Cr COGS for restored value.
</Example>
