A debit note reduces what you owe a supplier. **Posting** adjusts accounts payable and clears GRNI or expense — it does **not** move stock.

## Reasons

| Reason | Typical use |
|---|---|
| **GOODS_REJECTED** | Quality or inspection rejection |
| **PRICE_ADJUSTMENT** | Supplier credit for price difference |
| **SHORT_RECEIPT** | Billed for more than received |
| **QUALITY_CLAIM** | Post-delivery quality dispute |

## Creating a debit note

| Source | Source status | Line basis |
|---|---|---|
| Posted purchase invoice | `POSTED` | Remaining qty per PI line (`quantity − qty_debited`); first debit copies PI header discount/shipping/adjustment |
| Posted purchase return | `POSTED` | GRN lines mapped to PI lines for rate and account; PI optional if none posted for the GRN |

## PI-linked vs standalone

**PI-linked** — on post, `amount_applied = grand_total` and `amount_unapplied = 0`; reduces the linked invoice balance via `amount_debited`.

**Standalone (return-only)** — not tied to a specific PI at post; `amount_unapplied = grand_total`, capped by supplier open AP balance. Refund separately against the unapplied amount.

## Cancellation

Cancel reverses the journal and restores PI line `qty_debited` / header `amount_debited`.
