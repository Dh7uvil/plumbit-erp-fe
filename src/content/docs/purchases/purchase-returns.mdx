A purchase return sends received stock back to a supplier. **Posting** issues stock from the original GRN FIFO layers and clears **GRNI** — it does not adjust AP directly (use a **debit note** for that).

## Creating a return

Only from a **posted** goods receipt. Each line references a GRN line.

**Returnable qty** per GRN line:

- `qty_on_hold + qty_accepted`, or full GRN line qty if both are zero
- Minus qty already returned on prior posted returns

## Reasons and disposition

| Reason | Examples |
|---|---|
| **DAMAGED** | Physical damage in transit or storage |
| **QUALITY_REJECTION** | Failed inspection |
| **WRONG_ITEM** | Supplier shipped incorrect product |
| **OVER_SHIPMENT** | Excess qty not ordered |
| **OTHER** | Any other return scenario |

Disposition is **RETURN_TO_SUPPLIER** only.

## Cancellation rules (posted)

A posted purchase return **cannot be cancelled** when:

- Accounting period is locked
- A live (non-cancelled) **debit note** references the return

## Downstream documents

From a **posted** purchase return: **debit note** (to credit AP for the returned value).
