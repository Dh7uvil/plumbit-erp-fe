The purchase module covers ordering, receiving, billing, paying, and adjusting supplier transactions. Stock moves on **goods receipt** and **purchase return** post; accounting moves on **bill**, **supplier payment**, **debit note**, and **landed cost** post.

## Documents — mandatory vs optional

| Document | Required? | Moves stock | Posts accounting | Typical trigger |
|---|---|---|---|---|
| **Purchase order** | Optional but usual | Incoming only on issue | None | Plan/commit to supplier |
| **Goods receipt** | Required for stock receipt | On hand + on post | Dr Inventory, Cr GRNI | Physical delivery |
| **Bill** | Required for AP | None | Dr GRNI/Purchases, Cr AP | Supplier bill |
| **Supplier payment** | When paying | None | Cr bank, Dr AP (via advance) | Settlement |
| **Landed cost** | Optional | Revalues FIFO only | Capitalizes expense onto inventory | Freight/duty after receipt |
| **Purchase return** | Optional | On hand − on post | Dr GRNI, Cr Inventory | Reject/return goods |
| **Debit note** | Optional | None | Dr AP, Cr GRNI/expense | Supplier credit/refund |

## Common flow variants

| Pattern | Sequence |
|---|---|
| **Standard** | PO issue → GRN post → bill post → payment |
| **Bill before receipt (bill-before-receipt)** | PO issue → bill post → GRN post → payment |
| **Direct bill (no GRN)** | PO issue → bill post (no stock) → payment |
| **Import with landed cost** | GRN post → expense bill post → landed cost post → product bill post |
| **Supplier return** | GRN post → purchase return post → debit note post |
