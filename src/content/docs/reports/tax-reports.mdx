## Export evidence exceptions

Lists posted export sales invoices where linked delivery notes lack BL or customs attachments. Columns: invoice, date, customer, grand total, **days elapsed**, **window** (90 days).

Rows marked **overdue** when elapsed days exceed the window. Filter by **as of** date. CSV export available.

See <DocLink href="/docs/import-export/export-evidence">Export evidence</DocLink>.

## VAT 201 workflow

Run for the return period → reconcile to sales/purchase registers → resolve export evidence exceptions → compare to VAT GL recon before filing. VAT rules: <DocLink href="/docs/accounting/vat">VAT</DocLink>.
