## Reasons and movement types

| Reason | Line input | Movement type | GL on post |
|---|---|---|---|
| **OPENING_STOCK** | `qty_delta` (+) and unit cost | `OPENING_STOCK` | Dr Inventory, Cr Inventory adjustment |
| **COUNT** | `qty_counted` (delta = counted − booked) | `ADJUSTMENT` | Per net delta |
| **DAMAGE** | `qty_delta` (−) | `DAMAGE` | Dr Inventory adjustment, Cr Inventory |
| **FOUND** | `qty_delta` (+) and unit cost | `ADJUSTMENT` | Dr Inventory, Cr Inventory adjustment |
| **OTHER** | `qty_delta` (±) and unit cost if + | `ADJUSTMENT` | Per net delta |

<Callout type="note">
For increases, provide **unit cost** so FIFO layers are created. Decreases consume existing layers oldest-first.
</Callout>

## GL posting

Net inventory value change on post drives a single journal:

- **Increase** → Dr Inventory, Cr Inventory adjustment
- **Decrease** → Dr Inventory adjustment, Cr Inventory

Zero net value (e.g. count with no variance) posts no journal.
