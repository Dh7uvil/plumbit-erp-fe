Every tracked product has a separate balance in each warehouse. Quantities and reorder settings live on that balance — see <DocLink href="/docs/inventory/stock-concepts">Stock concepts</DocLink> for field definitions.

## Default warehouse

One warehouse per tenant is marked **default** (`is_default`). New purchase orders, sales orders, goods receipts, and delivery notes pre-fill this warehouse when none is chosen. Set it under <DocLink href="/docs/organization-and-access/warehouses-setup">Warehouses setup</DocLink>.

<Callout type="note">
A balance row is created on first movement or reservation for a product in a warehouse. Until then the product does not appear in that warehouse's stock list.
</Callout>

## What changes warehouse on-hand

| Document / action | Warehouse effect |
|---|---|
| Goods receipt post | On hand + (header warehouse) |
| Delivery note post | On hand − (header warehouse) |
| Stock transfer post | Source − / destination + |
| Stock adjustment post | ± (header warehouse) |
| Opening balances / opening adjustment | On hand + |
| Sales / purchase return post | ± per disposition |
| QC scrap (inspection approve) | On hand − |

Full movement-type mapping: <DocLink href="/docs/inventory/how-stock-changes">How stock changes</DocLink>.

## Viewing balances

The stock list shows one row per product per warehouse. Filter by warehouse, branch, or category. Drill into a row to see FIFO cost layers and recent movements.
