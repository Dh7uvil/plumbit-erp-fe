Packages group sales order lines into physical cartons for shipping. **Packing does not change stock** — stock is issued when the delivery note is posted.

## Creating a package

| Field | Purpose |
|---|---|
| **Sales order** | Required source — lines come from SO lines |
| **Delivery note** | Optional link to a posted DN |
| **Dimensions / weight** | Length, width, height, gross/net weight, CBM |
| **Package number** | Carton or pallet identifier |
| **Shipping marks** | Marks on outer cartons |

Lines reference `sales_order_line_id`, product, quantity, and packing attributes (batch, serial where applicable).

## What does not happen

- No stock reservation or issue on pack
- No GL entries
- No VAT impact

Stock already moved on delivery note post. See <DocLink href="/docs/import-export/trade-stock-and-accounting-impact">Trade stock and accounting impact</DocLink>.

## Import / export
