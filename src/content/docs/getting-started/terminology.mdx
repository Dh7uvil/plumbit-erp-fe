Concise glossary for terms used across Plumbit ERP documentation. Each entry links to the canonical page for detail.

| Term | Meaning | Canonical page |
|---|---|---|
| **Draft** | Saved but not finalized — editable, no stock or GL impact | <DocLink href="/docs/getting-started/working-with-documents">Working with documents</DocLink> |
| **Posted** | Finalized — stock and/or journal entries written | <DocLink href="/docs/getting-started/working-with-documents">Working with documents</DocLink> |
| **Cancelled** | Voided posted document — reversed where allowed | <DocLink href="/docs/getting-started/working-with-documents">Working with documents</DocLink> |
| **Reserved** | Quantity held for a confirmed sales order | <DocLink href="/docs/inventory/stock-concepts">Stock concepts</DocLink> |
| **Available** | On hand minus reserved minus QC hold | <DocLink href="/docs/inventory/stock-concepts">Stock concepts</DocLink> |
| **GRNI** | Goods received not invoiced — inventory received before supplier bill | <DocLink href="/docs/purchases/goods-receipts">Goods receipts</DocLink> |
| **AR / AP** | Amounts customers owe you / you owe suppliers | <DocLink href="/docs/accounting/accounts-receivable">Accounts receivable</DocLink>, <DocLink href="/docs/accounting/accounts-payable">Accounts payable</DocLink> |
| **FIFO** | First-in-first-out inventory costing | <DocLink href="/docs/inventory/inventory-valuation">Inventory valuation</DocLink> |
| **Landed cost** | Freight, duty, and other charges capitalized onto receipt layers | <DocLink href="/docs/purchases/landed-costs">Landed costs</DocLink> |
| **PDC** | Post-dated cheque tracked through issue, deposit, and clear | <DocLink href="/docs/accounting/cheques-and-pdc">Cheques and PDC</DocLink> |
| **TRN** | Tax Registration Number for UAE VAT | <DocLink href="/docs/accounting/vat">VAT</DocLink> |
| **Place of supply** | Emirate used for UAE VAT on a transaction | <DocLink href="/docs/accounting/vat">VAT</DocLink> |
| **Export evidence** | BL/AWB or customs proof for zero-rated export VAT | <DocLink href="/docs/import-export/export-evidence">Export evidence</DocLink> |
| **Opportunity** | CRM deal tracked through a pipeline | <DocLink href="/docs/crm/opportunities-and-pipelines">Opportunities and pipelines</DocLink> |
| **Period lock** | Date before which posting and cancellation are blocked | <DocLink href="/docs/accounting/period-lock">Period lock</DocLink> |

For module relationships, start at <DocLink href="/docs/getting-started/system-overview">System overview</DocLink>.
