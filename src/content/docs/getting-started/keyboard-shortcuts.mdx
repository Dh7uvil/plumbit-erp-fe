Keyboard shortcuts speed up navigation and common page actions. Single-letter shortcuts are suppressed while focus is in an input, textarea, or open dialog.

Press **Cmd+/** or **`?`** anywhere to open the in-app Help dialog with this list.

## Reference

| Keys | Action |
|---|---|
| `⌘K` / `Ctrl+K` | Open or close page search (command palette) |
| `Esc` | Close search or dialog |
| `⌘[` / `Alt+←` | Browser back |
| `⌘]` / `Alt+→` | Browser forward |
| `⌘/` or `?` | Help and keyboard shortcuts |
| `/` | Focus sidebar search |
| `⌘B` / `Ctrl+B` | Collapse or expand sidebar |
| `N` | Click first **New …** page action |
| `E` | Click first **Edit …** page action |
| `↑` `↓` `Enter` | Move and select in command palette |

## Notes

- **`N`** and **`E`** trigger the first matching action button on the current page (`data-page-actions`). If no such button exists, nothing happens.
- Command palette navigation is documented in <DocLink href="/docs/getting-started/navigation-and-search">Navigation and search</DocLink>.
