Notification **preferences** control which channels Plumbit ERP may use when the system sends alerts. There is **no in-app notification inbox** yet — toggles only affect future delivery, not a message feed.

<AppLink href="/settings/notifications">Open notification settings</AppLink>

## Channels

| Toggle | Default | Effect |
|---|---|---|
| Email notifications | On | System emails (e.g. payment reminders) |
| In-app notifications | On | Reserved for future in-app delivery |
| WhatsApp notifications | Off | WhatsApp channel when enabled by your tenant |

Changes save via API. Unsaved edits trigger a leave-page warning.

## What is not included

- No notification history or read/unread feed
- No per-event-type granular rules in settings
- No user-configurable payment reminder templates (rules are managed separately — see <DocLink href="/docs/collaboration/payment-reminders-and-emails">Payment reminders and emails</DocLink>)

For features that are not available at all, see <DocLink href="/docs/collaboration/whats-available">What's available</DocLink>.
