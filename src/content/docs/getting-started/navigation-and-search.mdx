Plumbit ERP navigation is organized by module in the sidebar. Use inline sidebar search or **Cmd+K** (Mac) / **Ctrl+K** (Windows) to jump to any page, report, or documentation entry.

## Sidebar groups

| Group | Examples |
|---|---|
| Overview | Dashboard, Reports |
| CRM | Customers, leads, opportunities, activities |
| Sales | Quotations through customer payments |
| Purchases | Suppliers, purchase orders and bills (one workspace), goods receipts, landed costs |
| Shipments | Packages, shipments |
| Inventory | Products, stock, movements, transfers |
| Accounting | Chart of accounts, journals, bank, VAT |
| Masters | Currencies, taxes, charge types |
| Settings | Profile, password, notifications |
| Administration | Users, roles, audit logs |

Items you cannot access are hidden based on your permissions. **Reports** appears only when you have at least one report permission. **Purchases** appears when you can read purchase orders.

## Sidebar search

The **Search…** field at the top of the sidebar filters navigation items, the report catalog, and documentation pages. Press **`/`** to focus sidebar search (ignored while typing in a form field).

When searching, all nav groups expand to show matches.

## Command palette (Cmd+K)

Opens a full-screen search over the same scope as sidebar search — **pages and reports only**, not individual records.

| Behavior | Detail |
|---|---|
| Empty query | Shows recent destinations (6, stored locally) plus browse shortcuts |
| Match fields | Label, group, href, keywords |
| Navigate | `↑` / `↓` to highlight, `Enter` to open, `Esc` to close |

For keyboard shortcuts beyond search, see <DocLink href="/docs/getting-started/keyboard-shortcuts">Keyboard shortcuts</DocLink>.

## Mobile and collapse

On mobile, tap the menu icon to open navigation in a drawer. On desktop, **Cmd+B** / **Ctrl+B** collapses the sidebar; state is remembered per browser.
